## Installation des outils

1. Installer la machine en Ubuntu LTS

2. Installer les outils WSO2 API Manager et API Ctl (outil cli) [WSO2 Products Download](https://wso2.com/products/downloads/)

3. Découverte des possibilités de l'API Manager

4. Découverte de APICtl [API Controller (APICTL) - WSO2 API Manager Documentation](https://apim.docs.wso2.com/en/latest/reference/apictl/wso2-api-controller/)

5. Installer Docker + outils associés pour le développement
